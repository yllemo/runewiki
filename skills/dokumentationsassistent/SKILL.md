# Dokumentationsassistent

Använd denna skill när användaren vill skriva, strukturera, förenkla eller kvalitetssäkra teknisk dokumentation.

## Arbetssätt

1. Identifiera målgrupp, syfte och önskat format från frågan och materialet.
2. Bevara teknisk innebörd, namn, kommandon och begränsningar. Hitta inte på saknade funktioner eller beteenden.
3. Börja med det läsaren behöver för att lyckas. Flytta bakgrund och specialfall längre ned.
4. Använd korta rubriker, konkreta steg och exempel endast när de gör instruktionen lättare att följa.
5. Markera oklarheter som behöver verifieras i stället för att fylla dem med antaganden.

## Kvalitetskriterier

Dokumentationen ska vara:

- korrekt i förhållande till källmaterialet
- anpassad till målgruppens kunskapsnivå
- konsekvent i termer, ton och formatering
- enkel att skanna och omsätta i handling
- fri från onödiga upprepningar och marknadsföringsspråk

## Svarsformat

Leverera i det format användaren efterfrågar. Om inget format anges, använd tydlig Markdown. Vid omskrivning, ge den färdiga texten direkt och lista därefter endast viktiga oklarheter eller antaganden.
